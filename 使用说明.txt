客堂管理系统 — 使用说明
========================

一、打开系统
    正式使用：通过寺院在线网址访问，使用系统账号登录。
    本地备用：双击「启动客堂系统.bat」（Windows）或「客堂管理系统.app」（macOS），
    系统会用 Chrome/Edge 浏览器打开本地版，无需安装任何软件。
    注意：
    - 在线网址是大家看到的同一份数据，日常多人协同请使用在线网址。
    - 本地版仅用于无网络时的应急、开发演示或恢复备份。
    - 本系统由 index.html、styles.css、js 文件夹、lib 文件夹等多个文件组成，
      复制到 U 盘或别的电脑时，请复制整个「客堂管理系统」文件夹，不能只复制单个文件。
    - 请使用启动脚本打开本地版；如果直接双击 index.html，浏览器可能无法加载本地数据文件。

二、登录系统
    首次打开后，页面中央会出现登录浮层，请选择账号并输入密码。
    默认账号（仅用于首次初始化或测试）：
    - 管理员：admin / admin
    - 知客师：zhike / zhike
    首次登录后，请立即修改默认密码（系统设置 → 用户管理）。

    权限区别：
    - 管理员：系统设置、用户管理、房间床位、备份恢复、全部业务。
    - 知客师：日常住宿、预约、房态、用斋、房务、报表、历史查询。
    - 厨房 / 房务 / 只读：由管理员创建对应角色账号，仅开放相关视图。

    在线模式说明：
    - 登录成功后，系统会从云端同步房态数据，首次约需 10–15 秒，请稍候。
    - 同步完成后若版本未变，后续刷新会更快（浏览器会复用已有快照）。
    - 住宿管理看板只显示「有可用床位且非备用房」的房间，数量可能少于云端房间总数。
    - 从旧版 ketang.db 迁移到在线时，guests / 用斋 / 营期等表若本地未导出，在线库可能缺历史明细。

三、日常使用
    1. 客堂大盘：查看今日 KPI、三张运营图表（床位/到离/寮别），以及「今日用斋」板块（标题下显示在寺人数与早/午/药人次，下方直接展示分餐饼图、身份统计与不用斋名单）。
    2. 在住挂单：独立页面查看全部在住人员，支持搜索；在此办理续住、换床、用斋、退房等。
    3. 住宿管理：查看各楼层房态网格，点击房间可展开床位明细并办理入住。
    4. 住宿办理：侧边栏进入「住宿办理」，分两个 Tab：
       · 现场入住 — 填写「姓名 / 法名」、性别、手机号、入住日期、分配床位等，可登记押金/房费；
         页面下方支持 CSV 批量导入法会名单（在线模式同样可用，单次最多 100 条）。
       · 提前预约 — 登记未来入住人员（可不选床位，填房间偏好），可选择营期、班级与用斋需求；
         列表中可「确认」「转入住」「取消」「No-show」；转入住会自动切到「现场入住」并预填信息，只需选床。
       「身份」选项为：法师、沙弥、行者、老师、管理员、义工、营务、学员、客人、工人。
    5. 编辑挂单：在住挂单或历史查询中点击「编辑」，可修改姓名/法名、
       性别、身份、手机号、身份证、日期、营期、班级、备注。
    6. 删除挂单：在住列表或历史查询中点击「删除」，可彻底清除误登记记录。
    7. 续住：在住列表中点击「续住」，修改预离日期。
    8. 换床：在住列表中点击「换床」，选择新床位。
    9. 用斋：在住挂单页点击「用斋情况」列或操作菜单「用斋」；
       可设置默认早/午/药石，再按日勾选「跳过」某餐；未跳过则默认用餐。
    10. 退房：在「在住挂单」页面点击「退房」，可退还押金并填写退房备注。
    11. 收款信息：挂单时可填写押金、房费、收款方式及备注，系统会一并记录。
    12. 紧急联系人：挂单时可填写紧急联系人及电话，自动归入住客档案。
    13. 打印凭证：在住列表或弹窗中点击「凭证」，可打印挂单凭证。

四、营期管理
    进入「信息管理」页面，点击「营期管理」标签：
    - 新增/编辑营期：填写营期名称、类型、性别、预计人数、起止日期、状态、备注。
    - 查看成员：点击营期卡片的「成员」按钮，可查看该营期下所有在住与预约人员。
    - 批量操作：在成员页可勾选多人，批量「取消」或标记「No-show」。
      批量取消在住成员会自动释放床位。
    - 导出名单：点击「导出名单」可导出 CSV。
    - 排房建议：点击「排房建议」，系统会按营期性别与人数推荐可用房间。
      若专属寮房不足，会推荐「不限」房间作为调剂。

六、流动预测
    进入「流动预测」页面：
    - 今日预报：选择日期，查看预计到达/离开、实际入住/退房、营期汇总、
      房间变动清单，可导出 CSV 或打印。
    - 周预测：选择起始日期与未来周数（4/8/12 周），查看每周到离趋势、
      在住人数、身份构成、床位预警与调剂建议。

七、房务清洁
    进入「房务清洁」页面：
    - 退房后床位自动标记为「脏房」。
    - 清洁后点击「已净房」→「查房」→「可入住」，床位才可再次分配。
    - 床位损坏可点击「报修」，维修完成后点击「维修完成」。

八、报表
    进入「报表」页面：
    - 厨房用斋汇总：按日期统计，口径与看板一致（当日在寺挂单 + 当日待入住预约）；含按身份、按房间（在寺）、在寺跳过名单，可导出 CSV。「用餐人数」指当日至少吃一餐的人数。
    - 日报：查看指定日期的入住、退房、在住、收款、用斋数据。
    - 月报：用斋人次为逐日累加看板口径（非 raw 餐表 SUM）。
    - 营期统计：选择营期，按身份/班级/性别分组统计，可导出 CSV。

九、历史查询
    进入「历史查询」页面，可按日期、姓名/法名/手机号、房间号
    查找已退挂单记录。

十、信息管理（仅管理员）
    进入「信息管理」页面：
    - 房间管理：新增、编辑、删除房间。删除前需先删除该房间下所有床位。
    - 床位管理：新增、编辑、删除床位。有在住挂单时床位不可删除；状态支持「可用」「维修」。
    - 住客档案：新增、编辑、删除住客主档案。被挂单记录引用时不可删除。
    - 挂单记录：查看并编辑所有挂单；新增挂单请回「住宿办理 → 现场入住」；删除会同步清理用斋、收款记录。
    - 营期管理：见「四、营期管理」。

十一、系统设置（仅管理员）
    进入「系统设置」页面：
    - 用户管理：新增、编辑、删除系统账号。不能删除当前登录账号。
    - 导出数据库：生成 ketang.db 备份文件。
    - 从文件恢复数据：选择 ketang.db 或 JSON 备份覆盖当前数据。
    - 重置数据库：清空所有数据并恢复初始状态，请谨慎使用。

十二、导出台账
    进入「系统设置」页面，点击「导出 CSV 台账」，
    可用 Excel 或 WPS 直接打开，方便交报表。

十三、输入校验
    系统会自动校验：
    - 手机号：11 位，以 1 开头
    - 身份证：18 位
    - 预离日期不能早于入住日期
    - 同一手机号/身份证已有在住记录时会提示
    - 性别与房间类型不匹配时会提示（男房/女房/不限）

十四、备份（非常重要）
    1. 如果首页出现「今日尚未备份」黄色提醒，请立即备份。
    2. 进入「系统设置」页面。
    3. 点击「导出数据库」，保存为 ketang.db。
    4. 把 ketang.db 复制到 U 盘或另一台电脑。
    5. 如需恢复：点击「从文件恢复数据」，选择 ketang.db。

十五、数据存在哪里？
    通过寺院在线网址打开时：数据保存在 Cloudflare 云端数据库里，多人看到同一份数据，
    这是日常正式使用方式。
    本地启动脚本打开时：数据保存在本机浏览器的内部存储里，仅用于应急或备份恢复。
    本地模式迁移到在线：在本地版「系统设置」导出 ketang.db，再使用工具转换为 JSON 导入在线版。
    在线版备份：管理员可在「系统设置」导出 JSON 备份，也可在 Cloudflare D1 控制台做数据库级备份。

十六、在线多人访问
    如果使用寺院在线网址访问，大家使用同一套云端数据。
    打开网址后仍需输入系统账号密码。
    默认账号密码仅用于首次上线测试，登录后系统会提示立即修改密码。
    云端模式下，管理员可在「系统设置」导出 JSON 备份、从 JSON 恢复；也可在 Cloudflare D1 控制台做数据库级备份。

十七、注意事项
    - 请使用 Chrome 或 Edge 浏览器，不要用 IE。
    - 同一台电脑、同一个浏览器内的数据会自动保留。
    - 清理浏览器数据会导致本系统数据丢失，因此务必定期导出备份。
    - 默认账号密码仅用于首次登录，登录后请尽快修改。

十八、手机端与添加到主屏幕
    适用场景：知客师临时用手机查看房态、确认预约、现场办理入住/退房。
    不适合：大型活动排房编辑、复杂报表分析（请用电脑浏览器）。

    添加到主屏幕（PWA）：
    - iPhone（Safari）：打开寺院在线网址 → 底部分享按钮 →「添加到主屏幕」→ 确认。
    - Android（Chrome）：打开网址 → 菜单 ⋮ →「添加到主屏幕」或「安装应用」。
    - 添加后从桌面图标打开，可全屏运行，体验接近 App。

    手机端功能概览：
    - 底部导航：房态 / 在住 / 办理 / 报表 / 更多。
    - 房态页：今日预到、预离、空床、脏房快捷卡片；可搜索房号/姓名。
    - 在住页：卡片列表，可直接点「续住 / 换床 / 退房 / 用斋」。
    - 办理页：入住与预约分步表单，底部固定提交按钮。
    - 更多：房态分布、房务、历史、预约、系统设置等（按账号权限显示）。

    离线说明：
    - 首次在线打开后，浏览器会缓存页面壳子；短暂断网可能仍可打开界面。
    - 业务数据以云端/本地数据库为准；离线时无法同步，请勿依赖离线办理正式业务。
    - 本地双击 index.html 打开的方式不支持添加到主屏幕，请使用在线网址或启动脚本。

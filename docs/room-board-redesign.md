# 房态看板 · 紧凑布局设计稿

## 设计目标

当前问题：房间卡片每间占一整行，床位列太宽，12间房需要大量滚动。
目标：一屏内可见所有房间，快速扫视房态，点击展开操作。

## 布局方案

```
┌──────────────────────────────────────────────┐
│ 📊 总 24  ·  已住 12 ██████░░ 50%  ·  空 8  │  ← KPI 单行
│ 脏房 2  ·  今日预约 4                         │
├──────────────────────────────────────────────┤
│ ○空闲  ●在住  ●脏房                          │  ← Legend
├──────────────────────────────────────────────┤
│ ▎男寮院                                      │
│ ┌─────┬─────┬─────┬─────┬─────┬─────┐       │
│ │ 101 │ 102 │ 103 │ 104 │ 105 │ 106 │       │  ← 6 列网格
│ │ ●●  │ ●○  │ ○○  │ ●●  │ ○○  │ ●●  │       │     每格 2em 高
│ └─────┴─────┴─────┴─────┴─────┴─────┘       │
│ ▎女寮院                                      │
│ ┌─────┬─────┬─────┬─────┬─────┬─────┐       │
│ │ 201 │ 202 │ 203 │ 204 │ 205 │ 206 │       │
│ │ ●●  │ ●○  │ ○○  │ ○○  │ ●●  │ ●○  │       │
│ └─────┴─────┴─────┴─────┴─────┴─────┘       │
```

## 房间缩略图规格

| 属性     | 值                   | 说明                            |
| -------- | -------------------- | ------------------------------- |
| 宽度     | `minmax(80px, 1fr)`  | 6 列网格，自适应                |
| 高度     | `3.5rem` (56px)      | 两行：房号 + 床位点             |
| 圆角     | `6px`                |                                 |
| 边框     | 1px `--color-border` |                                 |
| 左边框色 | 3px                  | 朱红=部分满, 灰=全空, 黛青=脏房 |
| 房号字体 | 13px bold            |                                 |
| 床位点   | 8px 圆点, 水平排列   | ●=占用, ○=空闲, ●=脏房          |

### 状态映射

```
空房 (0/n)   → 左边框灰色, 房号正常色, 全是○
部分满 (x/n) → 左边框朱红, 房号加粗,  ●○混合
全满 (n/n)   → 左边框朱红, 房号正常,   全是●
脏房/维护    → 左边框黛青, 房号正常,   ●变深色
```

## 交互行为

| 操作       | 响应                                |
| ---------- | ----------------------------------- |
| 悬停房间   | 边框变朱红, 轻微浮起                |
| 点击房间   | 展开床位详情面板（inline 或 modal） |
| 悬停床位点 | tooltip 显示姓名/状态               |

## 展开态（点击房间后）

```
┌─────────────────────┐
│ 101 · 男寮    ✕     │  ← 标题 + 关闭
├─────────────────────┤
│ ● 床1 · 张居士      │  ← 点击跳转编辑
│   早午斋 · 今日退    │
│ ○ 床2 · 空闲·净房   │  ← 点击快捷入住
│                     │
│ [+ 快速入住]         │
└─────────────────────┘
```

展开方式：在房间网格下方插入一行详情面板，而非弹窗。

## KPI 条规格

单行紧凑型，6 项横向排列，带微型进度条：

```
┌──────┬──────┬──────────┬──────┬──────┬──────┐
│总 24 │已 12 │████░░ 50%│空 8  │脏 2  │约 4  │
└──────┴──────┴──────────┴──────┴──────┴──────┘
```

| 属性     | 值         |
| -------- | ---------- |
| 高度     | 3rem       |
| 数字字号 | 22px bold  |
| 标签字号 | 11px       |
| 进度条高 | 4px        |
| 间距     | 1px 分隔线 |

## 与现有设计的差异

| 现有                          | 新设计                       |
| ----------------------------- | ---------------------------- |
| 房间卡片 200px 宽, 自适应高度 | 缩略图 80px 宽, 固定 56px 高 |
| 床位文字行（床1：张居士）     | 圆点阵列（●●○）              |
| 12 间需滚动 2-3 屏            | 一屏全览                     |
| 点击直接跳入住页              | 点击展开详情，可原地操作     |
| 无展开态                      | 展开后显示床位明细+快捷操作  |
